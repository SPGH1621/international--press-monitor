# International Press Monitor — نسخه رایگان ۰.۱

این بسته، **فقط نام و لینک پست‌های PDF** مربوط به شش نشریه را از پیش‌نمایش عمومی کانال `@demagazinesharing` جمع‌آوری می‌کند. **PDF، متن کامل و تصویر مقاله‌ها را دانلود یا منتشر نمی‌کند.** رابط کاربری فارسی در `public/index.html` و برنامه خواندن فهرست در `scanner.py` قرار دارد.

## راه‌اندازی رایگان روی GitHub

1. یک حساب در [GitHub](https://github.com/) داشته باشید.
2. مخزن **Public** به اسم `press-monitor` با شاخه `main` بسازید. (چون سایت و داده‌های نام فایل عمومی هستند، هیچ اطلاعات شخصی در مخزن نگذارید.)
3. فایل‌های داخل این بسته را، با **حفظ پوشه مخفی `.github/workflows`**، در ریشه مخزن آپلود کنید. اگر GitHub در مرورگر پوشه مخفی را نگه نداشت، `daily.yml` را جداگانه از مسیر `Add file → Create new file` با نام `.github/workflows/daily.yml` ایجاد کنید و محتوایش را قرار دهید.
4. در `Settings → Pages → Build and deployment` گزینه Source را روی **GitHub Actions** بگذارید.
5. در بخش `Actions → Daily press monitor → Run workflow` اجرا کنید. بعد از پایان موفق، لینک سایت در `Settings → Pages` ظاهر می‌شود.
6. از این پس، برنامه هر روز ساعت ۰۸:۰۰ به وقت تهران برای بررسی کانال **در صف اجرا قرار می‌گیرد**. GitHub ممکن است تحت بار، اجرا را کمی به تأخیر بیندازد.

## دکمه به‌روزرسانی چه می‌کند؟

دکمهٔ داخل صفحه فقط جدیدترین `data.json` منتشرشده را بازخوانی می‌کند. برای **بررسی فوری خود کانال** قبل از ساعت برنامه‌ریزی‌شده، `Actions → Daily press monitor → Run workflow` را اجرا کنید.

## محدودیت مهم

دسترسی وب به `https://t.me/s/demagazinesharing` از محیط ساخت این بسته ممکن نبود. بنابراین دریافت زنده و ساختار دقیق فایل‌های این کانال هنوز باید در اولین اجرای GitHub Actions آزمایش شوند. اگر صفحه عمومی تلگرام در GitHub مسدود بود یا اسم فایل‌ها را نشان نداد، `data.json` وضعیت خطا را حفظ می‌کند و مرحله بعد اتصال مجاز از طریق Telegram API خواهد بود.

## آزمایش محلی

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
python scanner.py
python -m http.server 8000 -d public
```

بعد `http://localhost:8000` را در مرورگر باز کنید. فرمان `scanner.py` فقط وقتی اتصال اینترنت به تلگرام برقرار باشد داده واقعی دریافت می‌کند.

## درباره هزینه و حق نشر

- GitHub Pages و GitHub Actions برای این نوع استفاده سبک، با مخزن عمومی و در چارچوب سهمیه و شرایط GitHub، می‌توانند رایگان باشند.
- پست‌ها و نام فایل‌ها در سایت عمومی‌اند؛ کلیدها و توکن‌های شخصی را **هرگز** در GitHub Public ذخیره نکنید.
- این نسخه هیچ مقاله‌ای را بازنشر نمی‌کند. برای پردازش و ترجمهٔ PDFها در مراحل بعد، باید دسترسی و استفاده از فایل‌ها مجاز باشد.
